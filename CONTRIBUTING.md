# Contributing

Thanks for helping improve this educational lab.

1. Open an issue or draft a proposal before substantial changes.
2. Create a focused branch from `main` (for example, `docs/input-validation`).
3. Keep examples synthetic. Never include flags, recovered plaintexts, private keys, or unredacted challenge artifacts.
4. Add or update tests for behavior changes and run `python -m pytest`.
5. Use clear commits such as `feat: validate related-message inputs` or `docs: clarify safe disclosure`.
6. Open a pull request against `main` using the project template.

By contributing, you agree your contributions are provided under the MIT License.
